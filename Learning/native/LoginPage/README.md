## LoginPage

A mobile login screen built with React Native and Expo — part of my journey learning native mobile development.

https://github.com/user-attachments/assets/28509454-b89b-4a48-a7ee-89e65b8135b2

https://github.com/user-attachments/assets/5976f91d-4468-4bf9-9ff2-612b5f5298c8


It covers the basics: email/password inputs, show/hide password toggle, and social login buttons (Google, Facebook, Instagram). Nothing fancy, just getting comfortable with the fundamentals.

## Stack

- React Native + Expo
- Expo Router for navigation
- TypeScript

## Run it

```bash
npm install
npx expo start
```

Then scan the QR code with Expo Go on your phone, or press `a` for Android / `i` for iOS simulator.
